# Velen Homebrew tap

```sh
brew install --cask majcheradam/tap/velen
```

Velen is a macOS menu bar app for AI token usage. Requires macOS 14 or later
and CodexBar 0.60.2 or later. Source code is private; this repository contains
only the public installation recipe.

This early release is ad-hoc signed and not notarized by Apple. You may need
to approve the first launch through System Settings → Privacy & Security →
Open Anyway. Updates are verified with Sparkle Ed25519 signatures.

Website: https://velen.sh
